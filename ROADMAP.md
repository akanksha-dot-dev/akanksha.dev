# akanksha.dev — Product Roadmap

> Portfolio & AI Platform for **Akanksha** (Production AI Engineer at Samsung SDS).
> Built with Astro 7, Tailwind CSS v4, and Cloudflare Workers.

---

## Vision & Strategy

To position Akanksha as a top-tier Senior/Staff Production AI Engineer through a live, cyber-physical laboratory aesthetic where recruiters get instant skill validation (JD Matcher) and engineering leaders see verified architectural depth (AI Sandbox & Case Studies).

---

## Phases & Milestones

### Phase 1: Core Platform & Design System ✅ (Complete)
- [x] Foundation with Astro 7 + Tailwind CSS v4 `@theme` design tokens
- [x] "Cyber-Physical Laboratory" visual design (blueprint grid, glassmorphism, floating orbs)
- [x] Homepage with Hero, Metrics, AI Sandbox, and JD Matcher
- [x] Secondary pages: About, Experience (System Changelog), Projects, Speaking, Blog, Contact
- [x] Global Developer UX: Cmd+K Command Palette and IDE Status Bar
- [x] Cloudflare Workers deployment configuration & SEO metadata

### Phase 2: Interactive Demonstration & UX Polish 🟡 (Current)
- [ ] **Auto-Demo Simulation for AI Sandbox:** Automated typing and pipeline execution preview so first-time visitors see real-time pipeline execution without requiring explicit manual clicks.
- [ ] **Mobile & Responsive Optimization:** Comprehensive viewport validation for complex components (AI Sandbox, JD Matcher, Command Palette) on mobile screen sizes.
- [ ] **Interactive Micro-Feedback:** Sound effects toggle (subtle click/telemetry bleeps optional), copy-to-clipboard enhancements, and rich tooltips for pipeline nodes.

### Phase 3: Project Deep-Dives & Case Studies ⬜ (Upcoming)
- [ ] Dynamic project case study routes (`/projects/[slug]`)
- [ ] Architecture diagrams (Mermaid & SVG interactive node graphs) for key Samsung SDS and HCLTech projects
- [ ] Before/After engineering trade-off breakdowns with measurable latency, accuracy, and cost metrics

### Phase 4: Architecture Playground & Recruiter REPL ⬜ (Future)
- [ ] Visual Graph-RAG Pipeline Builder / Playground
- [ ] Recruiter CLI REPL with command inputs (`fetch --resume`, `match --jd`, `eval --pipeline`)
- [ ] Lighthouse 100 performance, accessibility, and SEO audit
