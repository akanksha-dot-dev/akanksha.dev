## Intent
Transform the site's global look and feel from a funky/cyberpunk aesthetic into an ultra-clean, minimalist, high-end enterprise AI engineering platform inspired by Linear, Anthropic, and Vercel. Fix visual bugs such as the logo spacing glitch and bottom status bar content collision.

## Key Files
- `src/styles/global.css`: Design system tokens, typography definitions, glass styles, scrollbars, and micro-animations.
- `src/layouts/BaseLayout.astro`: Global layout, navbar, Command Palette (Cmd+K), footer, and non-intrusive telemetry status bar.

## Specification
1. **Typography & Styling**:
   - Update `--font-heading` to use `'Plus Jakarta Sans', system-ui, -apple-system, sans-serif` with font-weight 700/800 and tight tracking (`tracking-tight`).
   - Clean up gradient classes to provide sleek, single-direction high-contrast text gradients (e.g. `from-teal-400 to-emerald-400` or `from-white via-slate-200 to-slate-400`), removing tacky multi-color splits on single words.
   - Set base background to deep space `#040711` with refined subtle grid overlay.
2. **Global Navigation & Brand Logo**:
   - Fix the logo: `<span class="flex items-center gap-2 font-bold tracking-tight text-lg text-white">...</span>` ensuring `akanksha<span class="text-(--color-teal)">.dev</span>` renders seamlessly without stray spaces.
   - Nav links: Clean pill hover states, responsive mobile drawer with backdrop blur.
3. **Streamlined Bottom Status Bar**:
   - Ensure the body has sufficient `padding-bottom` (e.g. `pb-12` or `pb-10`) so no footer or page element is obscured.
   - Refine status bar elements: System online pulse, branch `main`, verified latency ticker (12-20ms), IST clock, and clear link to contact/availability.
4. **Command Palette (Cmd+K)**:
   - Clean keyboard shortcuts display (`⌘K` / `Ctrl+K`), refined search input, instant local KB responses with streaming text animation, and ESC/arrow navigation.

## Constraints
- Pure Astro and vanilla CSS/JS (zero React/Vue client overhead).
- WCAG 2.2 AA compliant contrast.
