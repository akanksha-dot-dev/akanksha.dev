## Intent
Cloudflare deployment failed with `"Missing entry-point to Worker script or to assets directory"` because `wrangler.jsonc` lacked the `assets` directory configuration required by modern Wrangler (v3/v4) for static Astro sites. This Work Item configures the static assets directory in `wrangler.jsonc`, adds a direct deployment script to `package.json`, and updates `DEPLOY.md` to document the Cloudflare Workers static asset deployment workflow.

## Key Files
- `wrangler.jsonc`: Cloudflare configuration file. Needs `"assets": { "directory": "./dist", "binding": "ASSETS" }`.
- `package.json`: NPM scripts. Add `"deploy": "astro build && wrangler deploy"`.
- `DEPLOY.md`: Project deployment guide. Document Cloudflare Workers deployment instructions and configuration.

## Specification
1. In `wrangler.jsonc`:
   - Add `"assets": { "directory": "./dist", "binding": "ASSETS" }`.
   - Ensure `compatibility_date` and `compatibility_flags` are preserved.
2. In `package.json`:
   - Add `"deploy": "astro build && wrangler deploy"` in the `scripts` section.
3. In `DEPLOY.md`:
   - Document both Cloudflare Pages and Cloudflare Workers (Direct Wrangler CLI) deployment options.
   - Include troubleshooting notes on `assets.directory` and cache clearing.

## Constraints
- Do not modify `astro.config.mjs` (keep `output: 'static'`).
- Ensure no hardcoded secrets or account IDs in configuration files.

## Verification
- `npm run build` passes with 0 errors.
- `npx wrangler deploy --dry-run` succeeds without asset directory or entrypoint errors.
