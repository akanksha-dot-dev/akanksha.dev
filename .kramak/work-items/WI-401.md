## Intent
Transform the global foundation of the site into an ultra-modern, cyber-physical laboratory aesthetic. Introduce cutting-edge modern web capabilities: WebMCP (Web Model Context Protocol) tool exposure for browser AI agents, fluid typography, subtle Web Audio API feedback, top scroll progress indicator, and an enhanced Command Palette 3.0.

## Key Files
- `src/styles/global.css`: Core design tokens, glassmorphic utilities, custom scrollbars, animations, blueprint grid, and accessible focus states.
- `src/layouts/BaseLayout.astro`: Shell with SEO metadata, JSON-LD schemas, top scroll indicator, navigation, Cmd+K command palette, IDE telemetry status bar, WebMCP tools, and audio synthesis.

## Specification
1. In `src/styles/global.css`:
   - Refine `@theme` tokens for vibrant teal (`#00F0B5`), warm amber (`#F5A300`), deep space background (`#030712`), elevated surfaces, borders, and typography.
   - Implement fluid type scale, `text-wrap: balance` on headings, `text-wrap: pretty` on copy.
   - Implement frosted glass card styling (`.glass`, `.glass-static`) with `backdrop-filter: blur(24px) saturate(180%)`, crisp borders, and hover micro-elevation.
   - Implement top scroll progress bar styling (`#scroll-progress`).
   - Implement accessible focus rings and `prefers-reduced-motion` compliance.

2. In `src/layouts/BaseLayout.astro`:
   - Add top scroll progress bar that tracks page scroll position.
   - Enhance desktop and mobile navigation with active route indicators and quick contact badge.
   - Upgrade Command Palette 3.0 (`Cmd+K`) with expanded career knowledge base, instant action commands, streaming simulated AI response, and keyboard navigation.
   - Add WebMCP tool registration (`match_job_description`, `search_knowledge_base`, `fetch_candidate_dossier`, `run_rag_simulation`) using `document.modelContext.registerTool` or fallback if available.
   - Add subtle Web Audio API synthesizer for optional click/telemetry bleeps with mute/unmute toggle in bottom status bar.
   - Retain complete SEO meta tags, OpenGraph, Twitter cards, and JSON-LD schemas for Person and WebSite.

## Constraints
- Zero external client framework dependencies (pure Astro + vanilla TypeScript).
- No blocking or loud auto-playing audio (audio synthesizer is disabled by default or gentle, with mute state saved in localStorage).
- WCAG 2.2 AA contrast compliance.

## Verification
- `pnpm run build` passes with zero errors.
