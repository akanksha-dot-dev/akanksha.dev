## Intent
Provide the foundational cyber-physical design system, fluid responsive typography, enhanced Command Palette, and telemetry status bar according to DP-05, DP-06, DP-07, DP-08, DP-11, and DP-12.

## Key Files
- `src/styles/global.css`: Design tokens, glassmorphism, glowing borders, animations, typography.
- `src/layouts/BaseLayout.astro`: Header, navigation, Cmd+K modal, status bar, SEO, JSON-LD schemas.
- `public/_headers`: Security headers and caching rules.

## Specification
1. Update `src/styles/global.css` with:
   - Enhanced glass card styles with neon accents (`border-teal-500/20`, subtle hover glow, inner border highlights).
   - Fluid typography utility classes and responsive container rules.
   - Micro-interaction keyframes (glow pulses, status dots, telemetry scan lines).
   - WCAG 2.2 AA compliant focus indicators (`:focus-visible`) and reduced motion rules.
2. Update `src/layouts/BaseLayout.astro` with:
   - Command Palette 2.0 with instant action items (Run GenAI sample, Run FDE sample, Download Resume, Contact Akanksha, Explore Projects), search input, keyboard nav (Arrow Up/Down, Enter, Esc).
   - IDE Status Bar with branch indicator, live latency indicator, status tooltip ("Available for Senior AI Engineer Roles"), and system telemetry.
   - Mobile navigation menu with smooth transition, focus trap, and Escape key listener.
3. Update `public/_headers` with clean security headers (removing deprecated `X-XSS-Protection`).

## Constraints
- Do not introduce client-side React/Vue frameworks; keep pure Astro and vanilla TypeScript/JavaScript.
- Maintain WCAG 2.2 AA contrast ratios across all text and UI elements.
