## Intent
Reimagine the AI Architecture Sandbox from first principles into a polished, executive-ready interactive demonstration of production GenAI engineering. It must showcase real system architecture (Graph RAG, Google ADK, FAISS, RAGAS, Semantic Routing) without looking like a messy hacker terminal.

## Key Files
- `src/components/AiSandbox.astro`: The standalone interactive sandbox component.

## Specification
1. **Header & Mode Switching**:
   - Modern pill tabs: `Enterprise Graph RAG` | `Autonomous Agent Loop (Google ADK)`.
   - Subtle animated pulse indicating live simulated engine.
2. **Graph RAG Pipeline Flow**:
   - 4-Stage visual node chain:
     1. `01. Partition & Layout Extraction` (GMFT parser, table-aware chunking)
     2. `02. FAISS Vector Search` (Cosine distance, top-K subgraphs)
     3. `03. Graph Entity Enrichment` (Neo4j relationships, cross-page balance sheet links)
     4. `04. LLM Synthesis & RAGAS Guardrails` (Token-optimized GPT-4 / Llama-3)
   - Clicking any node opens the Node Inspector showing real architectural parameters and sample intermediate payloads.
3. **Architectural Comparison & Degradation**:
   - Toggle switch for "Semantic Router & Guardrails".
   - When enabled: High accuracy (92%), fast latency (240ms), clean verified output.
   - When disabled: Degraded state warning banner, hallucination highlight in red, lower RAGAS score (61%), longer token search time.
4. **Autonomous Agent Loop Mode**:
   - Google ADK multi-agent loop simulation with DAG steps: Objective Decomposition → Tool Call (MCP) → Verification Gate → Output Synthesis.
   - Guardrails toggle demonstrating safety harnesses.

## Constraints
- Pure vanilla client-side JavaScript (no external heavy libraries or runtime frameworks).
- All simulation data self-contained and instant.
