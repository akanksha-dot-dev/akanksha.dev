## Intent
Provide technical recruiters and hiring managers with an instantaneous, high-converting assessment tool that validates Akanksha's qualifications for Senior/Staff Production AI Engineer roles.

## Key Files
- `src/components/JdMatcher.astro`: Client-side JD regex matching engine and report generator.

## Specification
1. Implement real-time debounced analysis on `input`/`paste` events into `#jd-input`.
2. Expand the skill dictionary with comprehensive patterns across Agentic AI (Google ADK, LangGraph, CrewAI, MCP), RAG (Graph RAG, FAISS, Chroma, Hybrid Search, RAGAS), LLM Infra (GPT-4, Llama-3, FastAPI, Docker, Kubernetes, AWS Bedrock), and Enterprise ML.
3. Compute domain category scores across 4 key dimensions and render visual animated progress bars.
4. Render tailored STAR interview stories and technical talking points based on detected high-value keywords.
5. Provide a rich "Copy Candidate Match Dossier" action button for easy forwarding in recruiter Slack/Email.

## Constraints
- Client-side execution with zero external network or LLM API calls for instant zero-latency performance.
- Mobile friendly layout down to 320px screen width.
