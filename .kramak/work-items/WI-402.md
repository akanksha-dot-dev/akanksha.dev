## Intent
Upgrade the flagship interactive AI Architecture Sandbox into a cyber-physical laboratory centerpiece. It must prove Akanksha's deep system-level competence to visiting CTOs and engineering leaders through real data structures, animated SVG dataflow paths, degradation simulations, and a hands-free Auto-Demo mode.

## Key Files
- `src/components/AiSandbox.astro`: Full-width interactive sandbox component containing Graph-RAG visualizer, Google ADK Multi-Agent loop, deep node telemetry inspector, and auto-demo engine.

## Specification
1. In `src/components/AiSandbox.astro`:
   - Top Bar: Workload selector ("Analyze Samsung SDS Q4 Net Income", "Assess RAG accuracy over 200-page financial statements", "Explain Google ADK multi-agent state patterns"), Run Pipeline button, and "⚡ Auto-Demo" button.
   - SVG Animated Dataflow Connectors: Animated SVG connectors between nodes with pulsing light beams showing real-time data packets flowing through the pipeline.
   - 4-Stage Graph-RAG Nodes:
     1. `01. SEGMENT`: Partition PDF / GMFT Layout parser, table bounding boxes, token chunking.
     2. `02. FAISS SEARCH`: Dense cosine similarity, hybrid BM25 score, top-K embedding matches.
     3. `03. GRAPH ENRICH`: Neo4j entity linking, Cypher query traversal, knowledge graph triplet injection.
     4. `04. LLM INFERENCE`: GPT-4 / Llama-3 synthesis, RAGAS guardrail verification, faithfulness score.
   - Deep Node Telemetry Drawer / Modal: Clicking any node highlights it and displays intermediate technical payloads (JSON tokens, vector distances, entity triplets, prompt parameters).
   - Architectural Degradation Matrix:
     - Toggling OFF "Semantic Router": displays warning banner, context dilution diff (+420 unnecessary tokens), and ungrounded table interpretation.
     - Toggling OFF "RAGAS Guardrails": lowers faithfulness metric from 0.94 to 0.61, showing red hallucinated diffs in output box.
   - Tab 2: Autonomous Multi-Agent Loop (Google ADK):
     - Interactive multi-agent orchestration simulator (Manager Agent -> Planner -> Researcher -> Verifier -> Executor).
     - Streaming execution trace logs with expandable JSON tool payloads (e.g. `web_search`, `python_code_interpreter`, `mcp_tool_call`).
   - Auto-Demo Engine: Simulates typing, runs pipeline sequentially through nodes 1-4 with audio synthesizer trigger hooks, and displays final verified telemetry.

## Constraints
- Pure Astro + vanilla JS/TS (no React/Vue runtime).
- Fully responsive on mobile, tablet, and widescreen.
